Maintenance Manager v5.9.13 — Machine QR bulk download
========================================================

Changed from v5.9.12 only:
- public/app.js
- src/index.js

WHAT CHANGED
------------
1. Machines now have a "Download X QR codes" button beside the machine filters.
2. Bulk QR download respects the current Machines filters/search:
   - All machines shown -> downloads all shown QR codes.
   - Section filter (for example Smokeshield) -> only that section.
   - Search text -> only matching machines.
   - Section/search/status can be combined.
3. Bulk download creates one ZIP file containing one SVG per matching machine.
4. Downloaded SVG QR labels now include the machine number + machine name underneath the QR, plus location/section on a second line where available.
5. Individual "Download QR SVG" uses the same labelled format.
6. QR destinations are unchanged; they still open the operator maintenance request for that exact machine.

DEPLOYMENT
----------
Replace only the two changed files above in GitHub and deploy normally.

Cloudflare changes: NONE
D1 migration: NONE
R2 changes: NONE
Access changes: NONE

TEST
----
1. Open Machines with no search/filter and press Download QR codes.
   Confirm the ZIP contains one SVG per visible machine.
2. Select a section such as Smokeshield and download again.
   Confirm only that section is included.
3. Search for a machine name/number and download again.
   Confirm only the search results are included.
4. Open one machine -> QR Code -> Download QR SVG.
   Confirm the SVG has the machine number/name printed under the QR.
