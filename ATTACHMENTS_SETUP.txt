Maintenance Manager v5.5.1 — attachment storage notes

The attachment system still uses the private Cloudflare R2 bucket:
  maintenance-attachments
with Worker binding:
  ATTACHMENTS

If you already created this bucket in an earlier version, do not create another one and do not change the binding.

Upload behaviour
- Multiple files are supported on jobs and machines.
- Phone camera capture is available.
- Any signed-in maintenance user can add, rename/describe, open, download and delete files.
- All file types are allowed by default.
- Default maximum size is 25 MB per file.
- The Admin can change the file-size limit and file-type policy from /admin → Maintenance Manager Settings.
- This direct Worker upload flow limits the Admin setting to 95 MB. Larger-file support would use a direct/multipart R2 upload design in a future update.
