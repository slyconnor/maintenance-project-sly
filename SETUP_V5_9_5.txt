Maintenance Manager v5.9.5 — Parts fixes
=========================================

Base version
------------
Install this on top of v5.9.4.

Changed files only
------------------
- public/app.js
- src/index.js

What changed
------------
1. Fixed stock tracking unexpectedly becoming unticked when editing minimum/current stock.
   Stock tracking now only changes when the Track Stock checkbox is deliberately changed.
   Legacy true/1 stock-tracking values are also normalised safely.

2. Added editable Part Number to the Parts > Edit stock dialog.
   Existing part numbers are retained and remain available in stock views, job parts and search.

3. Fixed removing parts that already have history.
   - A truly unused part can still be permanently deleted.
   - A part referenced by jobs, stock movements or purchasing history is safely archived instead.
   - Archived/removed parts disappear from the normal active stock list and cannot be selected for new jobs.
   - Historical jobs, receipts and stock records are preserved.
   - The part can be restored later from Manage Data.

Deployment
----------
Replace only the changed files listed above in GitHub, then use your normal deployment process.

Cloudflare / database
---------------------
No Cloudflare configuration changes are required.
No D1 migration is required.
