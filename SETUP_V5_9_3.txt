Maintenance Manager v5.9.3 — Machine asset details
===================================================

This is a small patch on top of v5.9.2.

Replace ONLY these project files with the copies in this ZIP:
- public/app.js
- src/index.js

What changed
------------
- The existing required Asset ID field is now presented as "Machine number / ID".
- Added a separate optional "Asset number" field for company/fixed-asset tags.
- "Make" is now presented as "Manufacturer".
- Manufacturer and Model remain separate values.
- Existing machine Make values are automatically shown as Manufacturer; no existing data is lost.
- Asset numbers are optional, but when entered they must be unique.
- Machine search now includes machine number, asset number, name, section/location, manufacturer, model and serial number.
- Machine overview and Admin > Manage Data show the new asset number and manufacturer information.
- Quick-add machine flow also supports optional asset number and manufacturer.

No Cloudflare dashboard changes are required.
No D1 migration is required because machine records are stored in the existing shared JSON state.

Suggested test
--------------
1. Open Machines > Add machine (or edit an existing machine).
2. Confirm the form shows Machine number / ID, Asset number, Manufacturer and Model.
3. Save an asset number and manufacturer.
4. Re-open the machine and confirm the values remain.
5. Search the Machines list using either the asset number or manufacturer name.
