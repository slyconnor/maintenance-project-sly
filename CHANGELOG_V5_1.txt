MAINTENANCE MANAGER — V5.1 CHANGELOG
====================================

DEPLOYMENT FIX
* Replaced Pages-style `_worker.js` packaging with a real Worker entry point:
  `src/index.js`.
* Added `wrangler.jsonc` for Cloudflare Workers Static Assets.
* Static site is now declared under `assets.directory = ./public`.
* Added ASSETS runtime binding.
* Worker runs first for /api, /api/*, / and /index.html.
* Worker name is fixed to `maintenance` to match the existing Cloudflare Worker.
* `workers_dev` is false so the existing custom-domain setup can stay dashboard-managed.
* `keep_vars` is true for dashboard-managed runtime variables.

AUTHENTICATION / ADMIN
* Admin checks now fail closed if ADMIN_EMAILS is not configured.
* Improved Cloudflare Access identity lookup by deriving the official
  *.cloudflareaccess.com identity endpoint from the validated Access JWT issuer.
* Main document can perform a server-side redirect to /admin.html when the user
  authenticated with Cloudflare and their email is in ADMIN_EMAILS.
* Added /index.html?view=dashboard escape for admins who want the normal dashboard.
* Separate /admin.html Access application remains recommended as defence in depth.

DATABASE / API
* Continues to store shared state in Cloudflare D1; no browser localStorage.
* Added GET /api/health for deployment diagnosis.
* Health response reports V5.1, D1 binding/readiness, admin variable state and identity.
* Updated D1 setup error messages to refer to the Worker rather than Pages.

FRONT END
* Front-end functionality from V5 retained:
  - All Jobs default profile view
  - profile filtering
  - automatic/editable job numbers
  - editable completed jobs
  - dated time entries
  - dated part entries with per-use manual prices
  - saved parts/suppliers/sections
  - section-dependent machine selection
  - machine Asset IDs and history
  - PDF-print and Excel-compatible report export
  - read-only Raspberry Pi current-month display
