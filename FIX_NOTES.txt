Maintenance Manager v5.5.0

- Added public operator maintenance request form at /request.
- Changed each machine QR code to open its operator request form.
- Added engineer Requests inbox with pending badge.
- Any signed-in engineer can assign a pending request to any active engineer and accept it.
- Accepting a request creates a normal maintenance job and records the source request.
- Requests are stored in D1 and recent accepted requests remain visible for 90 days.
- Added automatic operator_requests schema creation plus migration 0003_operator_requests.sql.
- Kept R2 attachments private and unchanged; 25 MB remains the default via Admin Settings.
