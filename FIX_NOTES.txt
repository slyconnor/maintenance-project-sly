Maintenance Manager v5.8.1 changed-files package.

Includes all v5.8.0 Downtime & Purchasing features plus the machine identity fix:
- Downtime by machine now labels slices as Asset ID · Machine name.
- Jobs now link to the unique machine ID rather than relying on machine name alone.
