Maintenance Manager v5.8.0 changed-files package.

Built on v5.7.0, so it also contains the email notification + R2 changes from that release.
No manual D1 SQL migration is required.

Small revision: the Machines tab now has instant search, Section and Active/Archived filters, plus a Showing X of Y count for large machine lists.

Important: downtime is only counted when a job has Machine stopped enabled and a downtime start time. Leaving Back in production blank deliberately keeps that machine in the Currently Down list.
