Maintenance Manager v5.9.11 - Dashboard Spend Split + Ordered Search
=====================================================================

CHANGED FILES FROM v5.9.10
- public/app.js

WHAT CHANGED
1. Dashboard parts spend is now split into two figures:
   - Parts used: actual quantity fitted/used on jobs in the selected month.
   - Parts ordered: quantity recorded in the job's Parts ordered section in the selected month.
2. The existing machine-category spend donut is relabelled "Parts used by machine category" so it is clear it represents consumed parts.
3. Monthly report summary and Excel summary now show Parts used and Parts ordered separately.
4. Ordered purchase orders now have an instant search box.
   Search matches:
   - PO/order number
   - Supplier
   - Part name
   - Part code
   A "Showing X of Y" count appears while searching.

INSTALL
Replace only public/app.js with the file in this package, then deploy as normal.

CLOUDFLARE / DATABASE
- No Cloudflare dashboard changes.
- No D1 migration.
- No new bindings or environment variables.
